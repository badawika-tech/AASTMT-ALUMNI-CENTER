## 🌟 Overview
The AASTMT Alumni Center website is a highly polished, responsive, and interactive digital hub designed to keep graduates connected worldwide. Built with modern web technologies, it features a premium corporate aesthetic and complete bilingual support (English / Arabic) out of the box.

## ✨ Features
- 🌐 **Native Bilingual Localization**: Instantly toggle between English (Sora font) and Arabic (Cairo font) with smooth RTL/LTR layout transitions.
- 🎨 **Premium Aesthetic**: Modern "Bento Box" grid design, glassmorphism overlays, and a strict primary-blue corporate color palette.
- 📱 **Fully Responsive**: Flawless scaling and overflow protection on everything from 4K monitors down to small mobile phones, complete with a touch-friendly mobile hamburger menu.
- ⚡ **Interactive Modals**: Seamlessly animated popups for checking Syndicate Requirements, Degree Equivalency, Job Opportunities, and Official Merchandise.
- 🚀 **Vercel Ready**: Architected specifically to deploy directly to Vercel with zero additional configuration.

## 🛠️ Technology Stack
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React](https://reactjs.org/)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, Animations)
- **Typography**: Google Fonts (Sora & Cairo)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/badawika-tech/AASTMT-ALUMNI-CENTER.git
   ```
2. Navigate into the project directory:
   ```bash
   cd AASTMT-ALUMNI-CENTER
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌍 Deployment

This project is fully optimized for **Vercel**.

1. Push your code to your GitHub repository.
2. Log into your [Vercel account](https://vercel.com/).
3. Click **Add New > Project**.
4. Import your GitHub repository (`badawika-tech/AASTMT-ALUMNI-CENTER`).
5. Click **Deploy**. Vercel will handle the rest automatically!
